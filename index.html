🪷 ตั้งค่าเว็บไซต์ก่อนเผยแพร่

ไฟล์ GitHub Pages พร้อมใช้งานแล้ว แต่จำเป็นต้องใส่ลิงก์เว็บแอป Google Apps Script เพื่อให้ลงทะเบียนและบันทึกลง Google Sheets ได้จริง

  1. เปิด Apps Script และเผยแพร่แบบ Web app (สิทธิ์เข้าถึง Anyone)
  2. คัดลอก URL ที่ลงท้ายด้วย /exec
  3. เปิดไฟล์ index.html และเปลี่ยนค่าของ APPS_SCRIPT_WEB_APP_URL เป็น URL ที่คัดลอกมา
  4. อัปโหลด index.html ไปยัง GitHub และเปิดใช้ GitHub Pages

สำคัญ: ฝั่ง Apps Script ต้องใช้ไฟล์ apps_script/Code.gs เวอร์ชันในชุดนี้ ซึ่งอนุญาตให้ฝังหน้าใน GitHub Pages ได้
